{%- comment -%} Multi-language code tabs. Emits an empty marker; assets/js/codetabs.js absorbs the next N fenced code blocks (N = number of pipe-separated labels) into an accessible tab group. Because the code blocks stay ordinary Markdown fences, Rouge still highlights them at build time — no plugin required. Usage (place the marker, then one fenced block per label, IN THIS ORDER): {% raw %}{% include codetabs.html langs="Classic Java|Java 25" %}{% endraw %} ```java // Classic Java ``` ```java // Java 25 ``` This book standardizes on exactly two labels, Classic Java and Java 25 — the through-line is where Java 25 retires a classic idiom. Selecting a tab syncs every group on the page and is remembered across pages. {%- endcomment -%}
