Bibliography

The reference books behind this book.

This book is a runnable, opinionated reference that points at a small set of excellent books rather than displacing them. Every citation in the chapters is a pointer, something like "see Bloch item 1 for the full technique," not a substitute for reading the source. These are books we recommend, not books we wrote; nothing here copies them. If a title is useful to you, please go read it in full.

TitleAuthor(s)PublisherYearTopic
Design Patterns: Elements of Reusable Object-Oriented Software
The canonical Gang of Four catalogue this book's chapters track.		 Erich Gamma, Richard Helm, Ralph Johnson, John Vlissides Addison-Wesley 1994 Design patterns
Agile Software Development: Principles, Patterns, and Practices
The source of the SOLID principles this book builds its principles part on.		 Robert C. Martin Prentice Hall 2002 SOLID principles
Effective Java
Third edition; the source for the static-factory, Builder, and immutability idioms the Java substrate and idiomatic-Java chapters apply.		 Joshua Bloch Addison-Wesley 2018 Java idioms
Working Effectively with Legacy Code
Seams, characterization tests, and the dependency-breaking techniques the changing-inherited-code chapters adapt to Java.		 Michael Feathers Prentice Hall 2004 Legacy code
Refactoring: Improving the Design of Existing Code
Second edition; the behavior-preserving refactoring catalogue contrasted with Feathers in the legacy track.		 Martin Fowler Addison-Wesley 2018 Refactoring
xUnit Test Patterns: Refactoring Test Code
The four-phase test and test-double taxonomy behind the testing and characterization chapters.		 Gerard Meszaros Addison-Wesley 2007 Testing
Java Concurrency in Practice
The mechanics behind Semaphore, ReentrantLock, Condition, and safe publication that the resource-and-concurrency-patterns chapter builds on.		 Brian Goetz, Tim Peierls, Joshua Bloch, Joseph Bowbeer, David Holmes, Doug Lea Addison-Wesley 2006 Concurrency
Pattern-Oriented Software Architecture, Volume 2: Patterns for Concurrent and Networked Objects
The original Monitor Object and Active Object catalogue entries the resource-and-concurrency-patterns chapter teaches as Java idioms.		 Douglas C. Schmidt, Michael Stal, Hans Rohnert, Frank Buschmann Wiley 2000 Concurrency
Grokking Concurrency
Language-agnostic concurrency fundamentals, scheduling, and blocking-versus-non-blocking reasoning behind the virtual-threads chapter.		 Kirill Bobrov Manning 2024 Concurrency
The Pragmatic Programmer: Your Journey to Mastery
The source for DRY, orthogonality, and the Robustness Principle reviewed in the programming-principles appendix.		 David Thomas, Andrew Hunt Addison-Wesley / Pragmatic Bookshelf 2019 Programming principles
Clean Code: A Handbook of Agile Software Craftsmanship
The source for the Boy-Scout Rule, Code For The Maintainer, and the do-one-thing discipline behind Curly's Law in the programming-principles appendix.		 Robert C. Martin Prentice Hall 2008 Programming principles
The Mythical Man-Month: Essays on Software Engineering
The source for Brooks's Law in the programming-principles appendix.		 Frederick P. Brooks Jr. Addison-Wesley 1995 Programming principles

Citation discipline

Every citation in this book is a pointer, something like "see Bloch item 1 for the full catalogue entry," not a displacing summary. The books exist; if this book replaced reading them, it would do the authors and the reader a disservice.
